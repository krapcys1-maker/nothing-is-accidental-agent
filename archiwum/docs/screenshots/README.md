# docs/screenshots/

Katalog na pliki screenshotów eksperymentu. Spis i opis każdego zrzutu jest w `docs/SCREENSHOT_INDEX.md`.

## Nazewnictwo

`YYYY-MM-DD_HHMM_opis-etapu.png`

Przykład: `2026-07-11_1840_first-article-generated.png`

## Bezwzględny zakaz

Nie zapisuj tu zrzutów zawierających: klucze API, hasła, zawartość `.env`, dane logowania, prywatne wiadomości, wrażliwe dane osobowe. Jeśli taki zrzut powstanie — usuń plik i odnotuj w `SCREENSHOT_INDEX.md`.

## Uwaga

Pliki graficzne nie są tekstem — jeśli repo będzie wersjonowane, rozważ trzymanie ciężkich zrzutów poza gitem lub w Git LFS. Ten `README.md` utrzymuje istnienie katalogu.
