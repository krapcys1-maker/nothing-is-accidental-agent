# docs/code-snippets/

Katalog na **dłuższe, samodzielne fragmenty kodu** wyodrębnione z repo do celów dokumentacyjnych i artykułowych. Skrócone, opisane wycinki trzymamy w `docs/CODE_EXAMPLES.md`; tu lądują pełniejsze pliki (np. cały moduł Policy Engine w wersji z danego etapu, do pokazania „przed/po").

## Zasady

- Nazewnictwo: `YYYY-MM-DD_opis.<ext>` (np. `2026-07-11_policy_engine.py`).
- To kopie do celów pokazowych — źródłem prawdy jest kod w `app/`.
- Bez sekretów: żadnych kluczy, tokenów, realnych danych.
- Dodając snippet, opisz go w `CODE_EXAMPLES.md`.
